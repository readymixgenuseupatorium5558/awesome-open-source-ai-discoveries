# Selection and evidence

Include a project only when it has a clear use case, inspectable primary documentation, actionable setup information and a reason to belong in this collection. Write an original concise description. Do not copy another list's prose or imply endorsement by an upstream maintainer.

## Evidence levels

- **documentation-reviewed**: upstream documentation was read. No local installation, performance or security claim is implied.
- **contributor-tested**: a contributor supplies a dated report with versions, hardware, configuration, commands, input and observed output.
- **maintainer-tested**: a maintainer reproduces a documented run and links the evidence.

Tested entries need a `test_evidence_url`. A working URL, CI pass, GitHub star count or automated summary is not evidence that an application works. Review dates change only when the substantive documentation or test is reviewed again.

## Requirements and limitations

Do not infer RAM, VRAM, latency or accuracy from model size. Tie measurements to a configuration and workload. Distinguish code licenses from model weights, a cloud option from a local mode, and a research example from a supported application. Include an archived project only with an explicit caveat and a useful historical or educational reason.

## Maintenance

Review source changes and reported problems. Weekly link checks flag broken or inconclusive responses, but never delete entries or approve new claims automatically. Contributors can suggest an entry or provide a correction without running every listed model. Metadata automation supports editorial decisions; it does not manufacture testing evidence.

## Attribution

The catalog describes third-party work and links to its creators. No source code, model weights or media from upstream projects are redistributed here. Selection has no paid placement, affiliate scoring or minimum-star requirement. Original editorial text and scripts use this repository's MIT license; upstream terms remain separate.
